# عرض «تدريب المراقبين الجويين في التعامل مع أطقم المسيرات»

عرض تقديمي (٢٩ شريحة، مقاس 16:9) مبني على الورقة العسكرية المرفقة، ومستند إلى
وثائق ICAO (Doc 10019، Circular 328، الملحق ٦ الجزء الرابع، Doc 4444 / 9868 / 10056 / 9683 / 9432).

## الملفات

| الملف | الوصف |
| --- | --- |
| `../تدريب-المراقبين-الجويين-المسيرات.pptx` | العرض الأساسي القابل للتحرير (مع ملاحظات المتحدث لكل شريحة) |
| `../تدريب-المراقبين-الجويين-المسيرات-معاينة.pdf` | معاينة بصيغة PDF (صور بمقاس 150dpi، للاطلاع فقط) |

## بنية العرض

1. الغلاف · محاور العرض
2. المبحث الأول — الإطار المفاهيمي والتنظيمي (٧ شرائح)
3. المبحث الثاني — الاحتياجات التدريبية والعوامل البشرية (٦ شرائح)
4. المبحث الثالث — الإطار التدريبي المقترح وآليات تنفيذه (١١ شريحة)
5. الخاتمة

خطوط العرض: Tahoma (متوفر على Windows وmacOS)، والنص مضبوط على اتجاه من اليمين إلى اليسار.

## إعادة البناء

```bash
pip install python-pptx pillow arabic-reshaper python-bidi
python presentation/build.py      # ينتج ملف pptx في جذر المستودع
python presentation/qa.py         # فحص تجاوز النصوص وحدود الشرائح
python presentation/render.py     # معاينة صور تقريبية (preview/)
```

- `deckkit.py`: نظام التصميم (الألوان، الخطوط، الشرائح، البطاقات، العناوين).
- `tablekit.py`: جداول يمينية مع صفوف متبادلة اللون.
- `slides_a.py` / `slides_b.py` / `slides_c.py`: شرائح العرض.
- `notes.py`: ملاحظات المتحدث.

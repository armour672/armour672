# العرض التقديمي — ورقة «تدريب المراقبين الجويين في التعامل مع أطقم المسيرات»

الملف النهائي: `../ورقة-تدريب-المراقبين-الجويين.pptx` (‏٢٤ شريحة، ‏16:9، خط Arial، أرقام هندية).

## البنية
| الملف | الوظيفة |
|---|---|
| `deck/theme.py` | نظام التصميم: الألوان، الخطوط، العناصر (بطاقات، شرائح، أرقام)، دعم RTL والأرقام الهندية |
| `deck/build.py` | محتوى الشرائح وتخطيطها (٢٤ شريحة) |
| `deck/backgrounds.py` | معالجة الخلفيات: قصّ، تغميق، تدرّج، إطار ذهبي لصفحة الغلاف |
| `deck/preview.py` | توليد صور معاينة (PNG) من `deck/layout.json` للتحقق البصري |
| `assets/logo.png` | شعار معهد تدريب القوات الجوية (مستخرج من الملف الأول) |
| `assets/bg*/` | الخلفيات الأصلية والمعالجة |
| `deck/layout.json` | أوصاف الرسم لكل شريحة (يُستخدم في المعاينة) |

## إعادة البناء
```bash
pip install python-pptx pillow arabic-reshaper python-bidi
python3 deck/backgrounds.py   # خلفيات (مرة واحدة عند تعديل الصور)
python3 deck/build.py         # إنتاج ملف pptx
python3 deck/preview.py       # صور معاينة في presentation/preview/
```

## قواعد التصميم
- كلمة «محظور» أعلى كل شريحة وأسفلها، بين خطَّين ذهبيين، ورقم الشريحة بصيغة `-٣-` أعلى الكلمة السفلية.
- الأرقام الهندية (٠١٢٣٤٥٦٧٨٩) في كل النصوص العربية؛ أرقام الوثائق الدولية تبقى لاتينية (Doc 10019، EU 2019/947، 14 CFR 107).
- لا يُطبَّق تباعد أحرف (letter spacing) على النص العربي لأنه يقطع اتصال الحروف.
